# Paquete final de NexusKM

| Archivo | Uso |
| --- | --- |
| [Informe PDF](NexusKM_informe_integrado.pdf) | 40 páginas con los ocho entregables, modelos, diccionarios, resultados y manual |
| [Informe Word](NexusKM_informe_integrado.docx) | Versión editable del mismo informe |
| [Presentación PowerPoint](NexusKM_presentacion_integrada.pptx) | 17 diapositivas editables para exposición |
| [Presentación PDF](NexusKM_presentacion_integrada.pdf) | Consulta de las diapositivas sin PowerPoint |
| [ZIP del proyecto](NexusKM_entrega.zip) | Código, configuración de ejemplo, documentación, evidencias y artefactos |
| [SHA256SUMS.txt](SHA256SUMS.txt) | Integridad de los cinco archivos de entrega |

El ZIP incluye su propio MANIFEST-SHA256.json para contrastar cada archivo. Excluye .env, .git, dependencias locales, cachés y material temporal de construcción. Arranca con `scripts/start.ps1`; genera las credenciales en la computadora de quien lo ejecute.

La aplicación y el repositorio están preparados para la revisión del proyecto. El equipo debe registrar a sus integrantes y realizar el envío por el canal académico indicado. La fecha anunciada es el 27 de noviembre de 2026.
